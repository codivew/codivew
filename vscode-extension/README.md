# Codivew for VS Code

Review working tree, staged, or branch changes with Codivew and a local Ollama model.

Open Codivew from the Activity Bar and enter a valid Ollama URL. Codivew loads installed models from `/api/tags`; select a model and review range to preview its changed file and line counts, then click **리뷰 시작**. Findings are added to the Problems panel. Open the full report from the result card when needed.

Run `npm run test:extension` for VS Code or `npm run test:extension:cursor` for an installed Cursor app from the repository root.
